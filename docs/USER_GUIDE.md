# 使用指南

## 资料与阅读

1. 新建或选择知识空间，添加 Markdown 或 UTF-8 TXT 文件。
2. 打开资料，在“实时预览／源码／阅读”间切换。编辑会保存到本机工作区；保存失败时保留输入。
3. 使用阅读器目录定位章节，或通过“导出 Markdown”取得正文副本。
4. 在资料库展开筛选并选择“检索正文”，可调用本机关键词索引查找内容，无需 API Key。

`Ctrl / Cmd + K` 打开快速查找。该入口搜索标题、文件名、卡片记法和标签、普通对话标题／问题及空间；正文检索仍由独立入口完成。

## 模型与问答

在设置中添加自定义服务，填写接口公共前缀、API Key 和模型 ID。例如服务提供 `/v1/chat/completions` 时，公共前缀填写至 `/v1`。模型列表接口可选；获取失败时可手填 ID。

输入框上方可切换服务和模型，旁边的思考控件提供低／中／高／极高及模型默认。各模型分别记忆；切换设置不调用模型，正在执行的请求使用提交时的设置。具体档位是否可用取决于服务。

主问答默认普通 AI。勾选“参考资料”后才检索当前范围的文档。阅读器打开侧边 AI 后，可以选中词句并询问；引用出现在输入框上方，可展开或移除。“参考本文”另行决定是否发送更多正文。

回答中的来源可打开核对；下方“相关知识卡片”是本地匹配入口，不参与模型回答。停止请求会尝试断开连接，但上游已经受理的计算可能继续计费。

## 知识卡片

手动卡片支持标题、一句记法、Markdown 正文、标签和所属空间。编辑器提供实时预览与源码；明确保存后才提交，取消不会保存。

生成草稿有三个入口：

- 卡片页“AI 生成”：粘贴文字或代码，选择目标数量。
- 阅读选文“AI 生成卡片”：根据完整选文生成草稿。
- 阅读器“整篇按章节生成卡片”：确认分批计划后逐批处理，支持停止和手动重试。

可继续提出“第二张简短一点”“给第二张补个代码示例”，或勾选目标后请求合并。核对正文和来源，再保存勾选项；已保存项锁定以避免重复修改和写入。

普通问答不会自动把所有追问当成卡片修改。未保存的阅读卡片草稿只在本次打开期间保留，刷新或关闭会丢失。

## 工作区备份

左下角备份入口可导出工作区 JSON。导入前核对资料、草稿、会话与卡片数量；导入按事务替换工作区，失败回滚。不同浏览器和桌面应用的数据不会自动同步。

JSON 只覆盖工作区记录，不包含后端数据库、上传副本或模型密钥。桌面数据位置和整体备份边界见 [桌面版说明](DESKTOP.md)。
